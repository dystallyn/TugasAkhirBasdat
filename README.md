## Deskripsi Proyek🏗️

Database Minuman merupakan proyek tugas akhir mata kuliah Basis Data yang bertujuan untuk mengelola data minuman secara terstruktur dan terintegrasi. Sistem ini dirancang untuk membantu proses penyimpanan, pencarian, penambahan, pembaruan, dan penghapusan data minuman melalui antarmuka grafis yang terhubung dengan basis data.

Proyek ini mengimplementasikan konsep-konsep basis data relasional seperti pembuatan tabel, relasi antar tabel, query SQL, serta operasi CRUD (Create, Read, Update, Delete).

---

## Teknologi yang Digunakan🌐

### Microsoft SQL Server (SSMS)🛢

Microsoft SQL Server Management Studio (SSMS) digunakan sebagai sistem manajemen basis data untuk menyimpan dan mengelola seluruh data pada aplikasi. Database dirancang menggunakan tabel-tabel yang saling berhubungan sehingga data dapat dikelola secara efisien dan konsisten.

### SQL

SQL (Structured Query Language) digunakan untuk melakukan berbagai operasi pada database, seperti:

- Membuat database dan tabel
- Menambahkan data
- Menampilkan data
- Memperbarui data
- Menghapus data
- Membuat relasi antar tabel
- Menjalankan query dan laporan

### Java♨️

Bahasa pemrograman Java digunakan untuk membangun logika aplikasi dan menghubungkan antarmuka pengguna dengan database SQL Server.

### Java Swing (GUI)

Java Swing digunakan untuk membangun Graphical User Interface (GUI) sehingga pengguna dapat berinteraksi dengan sistem secara mudah melalui tampilan visual tanpa perlu menjalankan perintah SQL secara langsung.

Fitur GUI yang tersedia meliputi:

- Menampilkan data minuman
- Menambah data minuman
- Mengubah data minuman
- Menghapus data minuman
- Mencari data minuman

### JDBC

JDBC (Java Database Connectivity) digunakan sebagai penghubung antara aplikasi Java dan database SQL Server sehingga data dapat diproses secara langsung melalui aplikasi.

- Koneksi langsung ke database SQL Server

---

## Cara Menjalankan Program📝

1. Install Microsoft SQL Server dan SQL Server Management Studio (SSMS).
2. Import file database ke SQL Server.
3. Buka project menggunakan NetBeans atau IDE Java lainnya.
4. Sesuaikan konfigurasi koneksi database pada file `Koneksi.java`.
5. Jalankan program.
6. Gunakan fitur yang tersedia untuk mengelola data minuman.
